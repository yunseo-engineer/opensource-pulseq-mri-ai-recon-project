# Open-source Pulseq programming with self-supervised AI image reconstruction

> This project was conducted in **Boston** as part of the **Global Biohealth Engineering Hackathon** at the **Athinoula A. Martinos Center for Biomedical Imaging, Massachusetts General Hospital (MGH)**, within the Harvard–MIT research environment.

## Project

**Open-source Pulseq Programming with Self-supervised AI Image Reconstruction**

This project explored accelerated MRI acquisition and reconstruction using open-source **Pulseq** sequence programming and **self-supervised AI reconstruction**.

The main objective was to reduce MRI scan time while preserving image quality. Multiple acceleration factors and Cartesian undersampling strategies were evaluated, and reconstruction performance was compared across:

- Zero-filled reconstruction
- SENSE
- L1 Wavelet reconstruction
- Self-supervised AI reconstruction

Performance was evaluated using **NMSE, PSNR, SSIM, and image comparisons**.

## Presentation

The presentation in this folder summarizes the project motivation, experimental workflow, Pulseq sequence design, reconstruction methods, results, and key findings.
